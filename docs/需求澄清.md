## 1. 一句话概述

在沸点火锅点单演示应用（deliveryai-demo-zs45uv）的现有界面中新增夜间模式（深色主题）切换能力，使使用者在暗光环境下能够降低屏幕亮度刺激、舒适阅读与操作，同时不改变现有交互方式与信息架构、不引入后端依赖。

## 2. 背景与目标

### 背景

- 当前界面仅提供浅色主题（暖白/米色背景 `#fbf5ea`、深灰文字 `#211f1c`），在夜间或暗光环境下亮度过高，视觉疲劳明显。
- 项目已有 localStorage 持久化先例（`useElderlyMode` hook、语言偏好 `i18nextLng`），扩展主题切换的成本较低。
- 用户反馈暗光环境使用不适，期望界面可切换为深色呈现。

### 目标

- **GOAL-001**：用户可在界面中显式切换浅色/深色主题，切换后界面配色立即变化。
- **GOAL-002**：深色主题下主要页面（绑定餐桌、欢迎页、菜单点餐、订单履约、结账支付）的文字、按钮、表单均可读可操作，对比度满足基本可读性要求。
- **GOAL-003**：主题偏好通过 localStorage 持久化，刷新页面或再次进入后保持一致。
- **GOAL-004**：现有功能、布局与浅色模式表现不受影响。

### 不做

- **NG-001**：不引入多套自定义配色或主题编辑器，仅提供浅色/深色两套主题。
- **NG-002**：不改造后端接口与业务逻辑（项目本身为纯前端 SPA，无后端 API 调用）。
- **NG-003**：不覆盖第三方嵌入内容（本项目无第三方嵌入内容，此条为边界声明）。
- **NG-004**：不引入额外 UI 库或设计系统框架（遵循 AGENTS.md 约定）。
- **NG-005**：不使用 CSS Modules 或 styled-components（遵循 AGENTS.md 约定，统一 Tailwind 类名）。

## 3. 需求详情

### 用户场景

- **场景 A（夜间使用）**：用户在夜间或暗光环境下访问界面，期望界面以深色呈现，减少亮度刺激。
- **场景 B（切回浅色）**：用户在深色模式下想切回浅色，期望一键切换且当前操作状态不丢失。
- **场景 C（刷新后保持）**：用户选择了深色主题后刷新页面，期望主题选择保持不变。
- **场景 D（首次访问）**：用户首次访问，默认显示浅色主题（已确认：不跟随系统偏好，默认浅色）。

### 用户路径

1. 用户进入界面（绑定餐桌页 / 欢迎页 / 菜单页等任意页面）。
2. 用户在顶部导航栏（TopBar）找到主题切换入口（位于老人模式按钮旁，Moon/Sun 图标）。
3. 用户点击切换为「夜间模式」，界面即时切换为深色配色。
4. 用户继续操作（浏览菜单、下单等），当前页面状态不丢失。
5. 用户如需切回，点击同一入口切换为「浅色模式」。
6. 用户刷新或再次进入，主题偏好保持一致。

**异常路径**：
- localStorage 不可用时：主题选择降级为内存态，当前会话内有效，不报错不阻塞。

### 产品规则

- **PR-001**：主题切换为即时生效，无需刷新页面或重新加载。
- **PR-002**：主题切换入口位于 TopBar 中老人模式按钮旁，始终可见，不因当前视图状态变化而隐藏。
- **PR-003**：主题偏好的默认值为浅色主题（已确认：不跟随系统偏好，默认浅色）。
- **PR-004**：localStorage key 为 `dark-mode`，值为 `true` / `false`（参照 `elderly-mode` 命名惯例）。
- **PR-005**：localStorage 不可用时降级为内存态，不报错不阻塞（参照现有 useElderlyMode 模式）。
- **PR-006**：主题切换不影响当前页面状态（如已选菜品、购物车内容、视图路由）。
- **PR-007**：主题切换与老人模式、语言切换相互独立，不互相影响。
- **PR-008**：深色主题覆盖全部核心页面（绑定餐桌、欢迎页、菜单点餐、订单履约、结账支付），所有 UI 元素适配深色配色（已确认：覆盖全部页面）。
- **PR-009**：主题切换入口使用 Moon/Sun 图标按钮（浅色模式显示 Moon 图标提示切换为深色，深色模式显示 Sun 图标提示切换为浅色），与现有图标按钮风格一致（已确认）。

### 状态与反馈

- **成功**：用户点击主题切换入口后，界面配色在 250ms 内平滑过渡为另一主题（利用现有全局 transition），无闪烁。切换后通过图标变化（Moon ↔ Sun）辨识当前主题状态，并在页面顶部短暂显示提示消息。
- **失败**：localStorage 写入失败时静默降级为内存态，用户在当前会话内仍可正常切换，不显示错误提示。
- **空态**：首次访问（无 localStorage 记录）时默认显示浅色主题。
- **无权限**：不适用（纯前端功能，无权限控制）。
- **异常**：localStorage 不可用时降级为内存态，不报错不阻塞，主题切换功能正常工作。
- **保持不变**：现有功能（点餐、下单、服务呼叫、结账等）、布局结构、信息架构、老人模式、语言切换均不受影响。

### 关键文案

- 主题切换入口 aria-label：
  - 中文：`切换至夜间模式` / `切换至浅色模式`（参照现有老人模式 aria-label 格式 `切换至常规模式` / `切换至老人模式`）
  - 英文：`Switch to dark mode` / `Switch to light mode`
- 切换提示消息（参照现有老人模式消息格式 `已切换为老人模式` / `已切换为常规模式`）：
  - 中文：`已切换为夜间模式` / `已切换为浅色模式`
  - 英文：`Switched to dark mode` / `Switched to light mode`
- 主题切换入口仅使用图标（Moon/Sun），不显示文字标签，与现有图标按钮（Accessibility、Languages）风格一致。

### 关键表现要求

- **过渡动画**：主题切换应利用现有全局 CSS transition（250ms ease），实现配色平滑过渡，不闪烁。
- **对比度**：深色主题下文字与背景对比度应满足 WCAG AA 基本可读性要求（≥ 4.5:1 正文，≥ 3:1 大文字）。
- **视觉一致性**：深色主题应覆盖背景、文字、边框、按钮、卡片、弹窗（Dialog）等所有 UI 元素，不出现浅色残留区域。
- **图标**：图标颜色通过 `currentColor` 继承（项目约定），深色主题下自动适配。
- **图片**：菜品图片等 `<img>` 资源不需特殊处理，保持原样显示。
- **防闪烁**：在 `index.html` 内联脚本中于 React 挂载前读取 localStorage 并设置 html class，避免页面加载时主题闪烁（FOUC）。

## 4. 约束限制

- **权限要求**：不适用（纯前端功能，无权限控制）。
- **兼容要求**：需兼容支持 localStorage 的现代浏览器；localStorage 不可用时降级为内存态。
- **性能要求**：主题切换不应引入明显延迟（利用现有 CSS transition，无额外 JS 计算开销）。
- **稳定性要求**：localStorage 异常时必须自动降级为内存态，不影响核心业务功能。
- **实现边界**：
  - 在现有架构内实现，不引入新 UI 库、CSS Modules、styled-components（遵循 AGENTS.md）。
  - 不修改 `server/` 目录。
  - 不引入后端 API 调用。
  - 参照 `useElderlyMode.ts` 模式新增 `useDarkMode` hook。
  - 在 `index.html` 中增加挂载前的主题初始化逻辑（参照现有 i18n lang 设置模式），避免页面加载时闪烁。
  - 在 `tailwind.config.js` 中配置 `darkMode: 'class'` 选项并定义深色主题色板。
  - 在 `src/i18n.ts` 中同步添加中英文文案。
  - 在 `src/components/TopBar.tsx` 中老人模式按钮旁新增主题切换图标按钮。
  - 在 `src/App.tsx` 中集成 `useDarkMode` hook 并在主题切换时显示提示消息。
  - 在 `src/index.css` 中定义深色主题下的全局基础样式和老人模式增强对比度规则。

## 5. 验收标准

- [主流程] 在浅色主题下，用户点击 TopBar 老人模式旁的主题切换图标按钮后，界面配色应在 250ms 内平滑过渡为深色主题，背景变为深色、文字变为浅色，图标由 Moon 变为 Sun。
- [主流程] 在深色主题下，用户点击主题切换图标按钮后，界面配色应在 250ms 内平滑过渡为浅色主题，图标由 Sun 变为 Moon。
- [持久化] 在用户选择深色主题后刷新页面，页面应直接以深色主题加载，不出现浅色闪烁。
- [持久化] 在用户选择浅色主题后刷新页面，页面应直接以浅色主题加载。
- [覆盖范围] 深色主题下，绑定餐桌页、欢迎页、菜单点餐页、订单履约页、结账支付页的文字、按钮、表单、弹窗均可读可操作，无浅色残留区域。
- [可读性] 深色主题下正文文字与背景对比度 ≥ 4.5:1，大文字（≥ 18px 或 14px bold）对比度 ≥ 3:1。
- [独立性] 切换主题后，当前页面的购物车内容、视图路由、订单状态等不丢失。
- [独立性] 主题切换与老人模式、语言切换互不影响，可同时开启。
- [兼容稳定] 现有功能（点餐、下单、服务呼叫、结账、Demo 控制台）在深色和浅色主题下均正常工作。
- [降级] 在 localStorage 不可用的情况下，主题切换功能仍可正常使用（内存态），不报错不阻塞。
- [构建] `npm run build` 和 `npm run lint` 通过，无新增警告。
