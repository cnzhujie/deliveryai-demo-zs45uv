> 状态：已实现（代码开发节点产出，2026-09-16）

## 1. 实现路径概述

按 Spec D-5 裁决采用 **Tailwind `darkMode: 'class'` + 组件内 `dark:` 变体**，不引入 CSS 变量语义 token 层、CSS Modules、styled-components 或新 UI 库；不新增运行时依赖、不新增网络请求、不修改 `server/`。

数据流：

```
localStorage('theme') ─┬─► index.html 内联脚本（React 挂载前：html.dark + meta[theme-color]）
                       └─► useTheme()（useState 初始化 + useEffect 同步）
                                  │
                                  └─► TopBar 主题图标按钮（点击 toggle → 写 localStorage → 重渲染）
```

- 主题态唯一来源：`<html>` 上的 `dark` 类；`localStorage` 键 `theme`，取值 `light` / `dark`，默认 `light`。
- 默认浅色、**不跟随系统** `prefers-color-scheme`（D-3）。
- 切换不写业务状态、不写全局提示条 `state.lastMessage`（D-4、R13）。

## 3. 深色配色映射

深色变体只使用既有色板（rice / chili / amber / charcoal）的等价色阶与透明度，不新增品牌色系（REQ-003.5、假设 A3）：

| 语义 | 浅色 | 深色 | 说明 |
| --- | --- | --- | --- |
| 页面底色 | `bg-rice-100` | `dark:bg-charcoal-900`（#211f1c） | 与 `theme-color` 深色值一致 |
| 卡片/弹窗/顶栏/底部导航 | `bg-white`、`bg-rice-50` | `dark:bg-charcoal-700`（#34312d） | 层级高于页面底 |
| 卡片内嵌次级区域 | `bg-white`、`bg-rice-100` | `dark:bg-charcoal-900/60` | 比卡片更深的内嵌面 |
| 芯片/小控件 | `bg-rice-100`、`bg-rice-200` | `dark:bg-rice-100/10` ~ `/15` | 半透明亮色叠加 |
| 图片上浮层标签 | `bg-white/90` | `dark:bg-charcoal-900/90` | 保持浮层遮挡感 |
| 分割线与描边 | `border-charcoal-900/5` · `/10`、`border-white/80` | `dark:border-rice-100/10` · `/15` | 仅改颜色 |
| 主文字 | `text-charcoal-900` | `dark:text-rice-50` | 对比度 ≈ 11.9:1（卡片）/ 13.3:1（页面） |
| 次级文字 | `text-charcoal-700` | `dark:text-rice-200` | ≈ 10.5:1 |
| 辅助文字 | `text-charcoal-500` | `dark:text-rice-200/75` | ≈ 7.3:1（卡片） |
| 品牌强调（文字/图标） | `text-chili-500` · `600` | `dark:text-chili-100` | 深色底上 ≈ 10 ~ 13:1 |
| 提醒文字 | `text-amber-500` | `dark:text-amber-400` | ≈ 9.2:1 |
| 主按钮 | `bg-chili-500` + 白字 | `dark:bg-chili-600` + 白字 | 白字对比度由 4.32:1 提升到 5.37:1（AA） |
| 选中态浅底 | `bg-chili-50` | `dark:bg-chili-500/20` | 选中文字用 `chili-100`，≈ 8.7:1 |
| 徽章/图标容器 | `bg-amber-100`、`bg-chili-50` | `dark:bg-amber-400/15`、`dark:bg-chili-500/20` | 文字改用 `amber-400` / `chili-100` |
| 背景装饰光斑 | `bg-chili-100`、`bg-amber-100` | `dark:bg-chili-500/15`、`dark:bg-amber-400/10` | 保持低亮度点缀 |
| 深色面板内元素（商品 Hero、订单进度面板、会员卡、移动端徽章） | `bg-white/10` · `/15`、`text-amber-400`、`text-rice-200`、`bg-amber-400 text-charcoal-900` | 保持原值 | 这些面板在两种主题下均为深色，浅色点缀不构成残留浅色区块 |

进度面板中未激活步骤文字属于正文类文字（12px / 16px），浅色下即为低对比度；为满足 REQ-003.2，仅在深色下提升为 `dark:text-white/60`（≈ 5.8:1）与 `dark:text-white/70`（≈ 7.2:1），**浅色颜色保持不变**（REQ-006.1 零回归）。

## 4. 关键实现细节

1. **首屏无闪烁（NFR-004 / REQ-002.6）**：`index.html` 内联脚本位于 `<head>`，在样式与 React 之前执行；`useTheme` 在 `useState` 初始化阶段再次应用同一状态，避免 hydration 前后不一致。
2. **默认与回退（REQ-005.3 / REQ-005.4）**：无值、空串、非法值（如 `blue`）一律回退 `light`；`localStorage` 读写异常被 `try/catch` 捕获，降级为内存态，界面仍可切换且不报错。
3. **`theme-color` 同步（REQ-003.6 / R14）**：浅色 `#fbf5ea`（与 `index.html` 初始值一致），深色 `#211f1c`（与深色页面底色一致），在切换与首屏初始化两处同步。
4. **偏好隔离（REQ-002.5 / R12）**：`theme` 与 `i18nextLng`、`elderly-mode` 相互独立，互不覆盖。
5. **仅改颜色（REQ-003.4）**：所有改动均为颜色/描边/背景类，未改字号、间距、圆角、布局类，沿用既有 250ms 全局过渡。
6. **老人模式叠加（REQ-004）**：`.elderly` 的半透明文字覆盖规则（`text-white/40` 等）只出现在两种主题下均为深色的面板中，深色下依旧成立；深色下又额外提升了非激活步骤文字亮度，叠加场景对比度经实测全部达标。
7. **入口唯一（D-1 / REQ-001.1）**：仅在 `TopBar` 图标按钮组内新增一个入口；`bind` / `welcome` 不渲染顶栏，因此无入口、仅按主题渲染（假设 A1）；移动端底部导航保持 4 列。
8. **无提示（D-4 / REQ-001.6）**：切换不写 `SET_MESSAGE`，不弹阻塞式提示。

## 7. 残留风险与未覆盖项

1. **`bind` / `welcome` 无切换入口**：与假设 A1 一致（入口唯一在顶栏）。若产品要求这两视图内可切换，需追加入口，属范围变更。
2. **浅色模式既有低对比度项未修复**：如 `text-chili-500` 白字实心按钮（4.32:1）、`text-emerald-600`（3.77:1）在浅色下依旧低于 AA，保持零回归；如需修复应另开任务。
3. **深色下品牌强调文字使用 `chili-100`**（等价更亮色阶）：与浅色 `chili-500` 视觉存在色阶差异，属 Spec REQ-003.5 允许的替代色阶，如设计另有指定色值需回改映射表。
4. **第三方嵌入内容**：本仓库无适用对象（D-6），该边界目前无实际实现。
5. **自动化测试节点建议覆盖的用例方向**（对应 Spec 第 5 章验收标准）：
   - 浅色/深色切换即时生效、入口 `aria-label` 随主题与语言变化、入口全站唯一；
   - 深色下刷新首屏仍为深色、`meta[theme-color]` 分别为 `#fbf5ea` / `#211f1c`；
   - 切换不丢购物车与当前视图、不产生提示条、不发起 XHR/fetch；
   - `theme` 非法值与 `localStorage` 不可用时的降级与刷新回退；
   - 深色 + 老人模式叠加、底部导航保持 4 列；
   - 深色下完整链路（绑桌 → 欢迎 → 下单 → 订单 → 结账）可见文案无异常。
